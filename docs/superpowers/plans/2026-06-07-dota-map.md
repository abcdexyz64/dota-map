# Dota Map Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local Dota Map web app that safely swaps Dota 2 terrain `.vpk` filenames with backups, restore support, and a bilingual black-and-orange UI.

**Architecture:** Use a dependency-free Node.js local server. Keep filesystem mutation in `src/mapManager.js`, HTTP routing in `src/server.js`, and UI assets in `public/`.

**Tech Stack:** Node.js built-ins (`fs`, `path`, `http`, `child_process`, `node:test`), static HTML/CSS/JavaScript, PowerShell launcher.
